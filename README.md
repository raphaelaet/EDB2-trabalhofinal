Código feito para matéria Estruturas de Dados Básicos II. Implementa Quadtree e GeoHash-Trie para solução de zeladoria urbana.

Programa executado em C++ 17.

Deve funcionar em compiladores on-line.

Todo o código tem origem nossa, com exceção do geohash, que pode ser encontrado nesse outro repositório: [https://github.com/nmmmnu/geohash/blob/master/main.cc](https://github.com/nmmmnu/geohash/tree/master)
